### Welcome to my corner of GitHub — I'm justbonkblock 👋

Quietly breaking things since 2019.

I build interfaces with TypeScript, React and Next.js, with Tailwind and Vite doing most of the heavy lifting. Most of what I actually care about lives in the unglamorous parts — how fast a page paints, whether a component library is still coherent after the tenth feature, if the keyboard flow really works. If you're nearby and want to argue about layout shift, I'm usually around.
